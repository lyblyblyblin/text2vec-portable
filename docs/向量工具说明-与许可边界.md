# win一键向量模型计算字符串向量 上限输入token128 MiniLM-L12-v2

> 原文来自印象笔记，标签：向量
> 模型 `paraphrase-multilingual-MiniLM-L12-v2`（384 维，量化 ONNX），**输入上限 128 token**

## 特点

不用装 Python，不用 pip，不用装 7-Zip，不联网。

解压到 D 盘、U 盘或网盘目录都能运行；移动或改名都不影响，因为程序会读取自身旁边的 `model\`。

## 两条必须守住的边界

### ① 微软的运行库 DLL 不能单独拆分出来供人下载

`msvcp140.dll`、`vcruntime140.dll` 这几个文件，微软允许以「应用本地（app-local）」方式随你的应用一起分发，但不允许你单独提供下载、也不允许把运行库说成独立产品。

因此：**整个 zip 一起给没问题，如果只发「VC++ 运行库下载」就会越界。**

### ② 模型改过就必须标注

现在是原版量化模型，注明来源即可。如果你以后重新量化或剪枝，分发时要在说明里写「已修改」——Apache 2.0 明确要求标注。
